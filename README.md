# SIZEY Fashion Hub

React + TypeScript + Vite PWA. Каталог и логотип перенесены с sizey.ru 17.11.2026.
57 товаров; каталог является снимком, без синхронизации остатков. Платежи и авторизация пока не подключены. Демо-данные пользователя сохраняются в localStorage.

## Сборка

Требуется Node.js 22.

```bash
npm ci
npm run build
```

Для размещения используются файлы из `dist/`. Проект не зависит от хостинга Sites.

## GitHub Actions

При изменениях в `main` Actions проверяет TypeScript, собирает приложение и сохраняет архив `sizey-dist`. Для скачивания: Actions → успешный запуск → Artifacts.

Публикация на VPS по умолчанию выключена. Включать её нужно после проверки и подготовки сервера Ubuntu 24 по адресу 95.181.213.9, DNS и HTTPS для hub.sizey.ru.

Перед настройкой сервера проверьте через SSH, какие сервисы уже занимают порты 80 и 443:

```bash
sudo ss -ltnp '( sport = :80 or sport = :443 )'
command -v nginx
command -v apache2
command -v docker
```

На действующем сервере используется Docker: `sizey-proxy` (Caddy) направляет hub.sizey.ru в `sizey-hub:80`. Контейнер приложения монтирует `/var/www/sizey-hub` в `/srv` и читает `/srv/current`. Существующие app.sizey.ru и api.sizey.ru обслуживают бонусную систему. Не устанавливайте Nginx и не меняйте эти маршруты.

## Требования для автопубликации

- Отдельный SSH-пользователь `sizey-deploy`, без root и sudo.
- Каталог `/var/www/sizey-hub`, доступный на запись пользователю `sizey-deploy` и на чтение веб-серверу.
- В `~sizey-deploy/.ssh/authorized_keys` — публичный ключ публикации.
- В GitHub → Settings → Environments создайте `production`.
- Secrets окружения: `SSH_KEY` — приватный ключ публикации, `SSH_KNOWN_HOSTS` — проверенная запись ключа SSH сервера для 95.181.213.9. Сверьте отпечаток через доверенную консоль провайдера; не отключайте проверку ключа сервера.
- Ключи создаются на вашем устройстве; не отправляйте приватный ключ в чат и не добавляйте его в Git.
- GitHub → Settings → Secrets and variables → Actions → Variables: `DEPLOY_ENABLED` = `true` только после подготовки сервера.

Каждая сборка загружается в `/var/www/sizey-hub/releases/<commit>-<run>-<attempt>`. Передача происходит через tar по SSH. После успешной передачи атомарно переключается относительная ссылка `current` → `releases/<release>`, работающая и на хосте, и внутри контейнера. Проверка version.txt подтверждает публикацию точного релиза. Перезапуск Docker не требуется. Старые релизы сохраняются для отката. Первый релиз уже опубликован вручную с HTTPS. После настройки пользователя и секретов включите автопубликацию и запустите Actions → Build and deploy SIZEY → Run workflow.

HTTPS обязателен для service worker и установки PWA. Указатель DNS A для `hub.sizey.ru` должен вести на 95.181.213.9. AAAA задаётся только при настроенном IPv6 этого сервера.
